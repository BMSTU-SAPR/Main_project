# Отчет Мазеина В.С.
Разработка датчика SpO2 на микросхеме MAX30102. В качестве МК использована микросхема серии STM32f103. Питание и общение с внешним миром осуществляется посредством кабеля USB (VCP).
Для питания микросхем используются напряжения +3,3 и +1,8 В. Для преобразования питания используются линейные стабилизаторы XC6219.
Для отладки предусмотрен разъем SWD.
