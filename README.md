# Главный проект. Канал регистрации ЭМГ сигнала

Система регистрации и управления протезом представляет собой 1 микропроцессор и 8 каналов регистрации, состоящих из инструментального усилителя, ФНЧ, ФВЧ, блока масштабирования сигнала и АЦП

## Создание схемы электрической принципиальной

Поиск элементов, использующихся в СЭП, производился на сайтах:
* https://www.snapeda.com/ - SnapEda - коллекция посадочных мест, УГО и 3D моделей различных элементов
* https://componentsearchengine.com/ - также коллекция посадочных мест, УГО и 3D моделей различных элементов, поиск по которой производился после поиска в SnapEda

Для добавления компонентов в KiCad загруженные архивы элементов, содержащие посадочные места, 3D модел и символы были помещены в папку проекта в папку с расширением .pretty, после чего в редакторе посадочных мест были добавлены посадочные места, в редакторе символов символам были присвоены эти посадочные места.

После этого, с использованием добавленных элементов, была собрана СЭП. Для стандартных элементов - резисторов и конденсаторов - были выбраны посадочные места из библиотек KiCad. Добавлены саморезы и посадочные места для них. Производим проверку полученной СЭП и исправляем возникшие ошибки. 

Собранная СЭП представлена на рис. 1.

![S E P](../../../Desktop/SAPR/Main_project/Foto/SEP.png)
Рисунок 1. СЭП 1 канала регистрации 

Далее нажимаем "Обновить печатную плату" и получаем печатную плату, после чего производим её разводку. Сначала соединяем контакты, не относящиеся к питанию и земле. Потом проводим питание, и в конце проводим землю. Для избежания перегрева и перегорания дорожек питания были рассчитаны ширины дорожек питания с помощью встроенного калькулятора для силы тока 1А. Ширина дорожек получилась равной 0,5 мм. После проведения дорожек были скорректированы размеры печатной платы и произведена заливка платы GND. На слое шелкографии добавлены обозначения и подпись изготовителя.

Для всех элементов платы, взятых с сайтов SnapEda и ComponentSearch были выбраны 3D модели.
